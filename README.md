# Wasuthorn Ausrivong — Personal Website

🔗 **Live site:** [https://wonner163.github.io/WonnerWebsite/](https://wonner163.github.io/WonnerWebsite/)

Personal portfolio site built with plain HTML, CSS, and JavaScript — no frameworks or build tools. Hosted for free on GitHub Pages.

## Sections

- **About** — education, research areas, and skills
- **Experience** — work history
- **Projects** — robotics projects with links to slides, videos, and demos
- **Publications** — conference papers and journal articles
- **Awards** — scholarships, leadership, and patent
- **Contact** — email and downloadable CV

## Structure

```
index.html   — page content
style.css    — styling (light/dark aware, responsive)
script.js    — mobile nav toggle
assets/      — profile photo and downloadable CV
```

## Running locally

Just open `index.html` in a browser, or serve the folder with any static file server.
